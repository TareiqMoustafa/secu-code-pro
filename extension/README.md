# SecuCode Pro — Browser Extension

## التثبيت (Chrome / Edge / Brave)

1. افتح `chrome://extensions`
2. فعّل **Developer mode**
3. **Load unpacked** واختر مجلد `extension`
4. اضغط أيقونة الإضافة → Options
5. ضع رابط موقعك على Vercel مثل: `https://your-app.vercel.app`
6. احفظ، ثم افتح أي صفحة واضغط أيقونة الإضافة → فحص

## الملفات
- manifest.json — Manifest V3
- popup.html / popup.js — واجهة الفحص
- options.html — إعداد عنوان الـ API
- icons/ — أيقونات من شعار SecuCode Pro
