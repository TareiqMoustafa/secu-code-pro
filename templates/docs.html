واجهة برمجة مجانية 100%

استخدم محرك استخبارات التهديدات مباشرة في أدواتك، إضافات المتصفح، أو سكربتات الحماية — بدون مفاتيح معقّدة للبداية. قيمة سوقية حقيقية للمطورين وفرق الأمن.

POST /api/analyze

فحص رابط واحد عبر جميع المصادر + قواعد التهديد الحيّة

curl -X POST https://secu-code-pro.vercel.app/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"link":"https://example.com"}'

POST /api/bulk

فحص حتى 8 روابط دفعة واحدة — مثالي للقوائم والتحقق السريع

curl -X POST https://secu-code-pro.vercel.app/api/bulk \
  -H "Content-Type: application/json" \
  -d '{"urls":["https://a.com","https://b.com"]}'

GET /api/badge?domain=example.com

شارة ثقة SVG قابلة للتضمين في أي موقع — تسويق فيروسي مجاني

<img src="https://secu-code-pro.vercel.app/api/badge?domain=yoursite.com" alt="SecuCode" />

GET /r/{report_id}

تقرير عام قابل للمشاركة — رابط دائم لكل عملية فحص

https://secu-code-pro.vercel.app/r/SCR-A1B2C3D4E5F6

GET /api/domain/{domain}

استخبارات مجمّعة لنطاق: السجل + القواعد الحيّة + القوائم

curl https://secu-code-pro.vercel.app/api/domain/example.com
